# VoiceHub 控制台改进 · 2026-10-25

按用户要求逐项实现并验证。沿用当前配色与导航；运行中的 MQTT/设备接口保持兼容。

1. 对话窗口：桌面固定在视口范围、会话与消息各自滚动、标题和操作固定；手机布局有界。
   阅读历史时保持位置，加载更早消息保持阅读锚点。真实浏览器使用长列表验证。
2. 内置模型服务：ASR / LLM / TTS 分别由后端托管本地子进程，支持状态、启动、停止、重启。
   外部 HTTP（含用户自行启动的 localhost 服务）不提供进程控制。只操作自己拥有且验证身份的进程。
   生命周期/配置状态在界面区分；不以是否使用127.0.0.1判断归属。保留原有配置读取兼容。
3. 工具、MCP、技能与长任务：明确工具目录和权限，先支持日期/时间、系统信息、受限文件目录；
   接入管理员配置的 MCP 服务和技能指令；新闻/天气/音乐通过启用的工具或用户配置的来源执行。
   模型实际调用结构化工具；长任务持久排队、先即时确认，再异步播报结果，离线时不丢失或串会话。

验收：每一步独立提交；保留原测试，新增 API/进程生命周期/工具与异步播报集成测试。
浏览器验证长列表、按钮状态、失败提示和结果记录。测试使用临时目录与模拟模型/工具，
最终再用本机模型与实际设备验证适用路径。未配置的外部服务明确显示待配置，不能伪造成功。

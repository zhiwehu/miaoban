# EchoEar 已有设备升级与接入规格

用户已批准的范围：已有兼容 EchoEar ESP32-S3 / 16 MB 分区布局（物理 Flash 16 或 32 MB），普通用户通过桌面 Chrome 操作，无需终端；不支持空白板、其他型号、整片擦除。

模块与顺序：正式应用构建与发布清单 → 浏览器串口识别/备份/升级/恢复 → 配网提示 → 会话验收。

验收约束：
- 依赖固定版本并本地打包；串口和备份仅在用户电脑处理，不上传 Flash / NVS。
- 写入前核对芯片、Flash 容量、安全配置、精确分区表和现有应用指纹，未知目标拒绝写入。
- 升级前将受影响的应用、OTA 选择信息和设备设置保存到用户指定文件，并读回确认备份完整。
- 新应用写入非活动槽并读回校验，再更新一个 OTA 选择扇区；不写 bootloader、分区表和资源区。
- 保存的备份限定 MAC、分区和允许写入范围；提供恢复，不接受任意地址或整片擦除。
- 浏览器明确区分“应用写入成功”“设备上线”“语音验收通过”；软件模拟结果不能替代实机通过。
- 仅有真实芯片与指纹验证才能标注兼容；芯片相同不代表板型兼容。
- 当前没有 USB 设备时完成软件与模拟测试，实机刷写、断电恢复和语音验收保持未验收状态。

测试：后端 unittest、前端 Node 测试、官方 esptool 镜像检查、真实浏览器界面检查；USB 接通后进行设备验证。

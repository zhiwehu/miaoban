    指定目录文件整理
    
            
    只整理所选目录第一层的普通文件，按类型归入分类文件夹。子目录、隐藏文件和链接会跳过；不读取文件内容，不删除或覆盖文件。先预览再确认，支持撤销最近一次整理。
    
            
    
              
              
              
    
            
    
            
    试着说：“整理一下指定目录里的文件”。语音只生成方案，请在这里核对完整清单并确认执行。最多扫描 2000 项、整理 1000 个文件；操作过程中请勿更改目录或文件。
    
            
    
          
    
          
    
          
    
            添加与管理 MCP
          
    
            
    连接远程 MCP
    
            
    填写 Streamable HTTP 服务的完整端点，例如 https://example.com/mcp。保存时不会连接；启用后才验证工具。暂不支持旧版 HTTP+SSE 和 OAuth 登录。
    
            
    
              
              
              
              
              
    协议版本与自定义认证
                
                
                
    认证信息仅保存于后端，不会回填到页面或提供给模型。暂不支持修改已保存凭据；需要更换时删除后重新添加。
    
              
    
              
              
    
            
    
            
    
          
    
          
    
            
    上传自己的 MCP
    
            
    上传 JSON 服务配置（stdio 填 command，HTTP 填 type 和 url），或根目录含 mcp.json 和 Python 服务的 ZIP 包。上传后处于停用状态，启用时才会运行并验证。
    
            
    本地代码启用后以当前系统用户权限运行，并非安全沙箱。远程服务会收到调用参数。仅启用你信任的服务；不会自动安装依赖。ZIP 最大 2 MB、50 个文件，每个服务最多 20 个工具。
    
            下载可上传的回显示例

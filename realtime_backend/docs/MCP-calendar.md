# 日程与提醒 MCP

在 MCP 页面展开「日程与提醒 → 配置与测试」。首版使用平台本地日程库，尚未读取或同步 Apple 日历、Google Calendar、企业日历等外部日程；支持单次日程与提醒。

配置项：

- 时区：IANA 名称，默认 `Asia/Shanghai`。日期和时刻由主机解释，不依赖模型推算当前日期。
- 默认提前提醒：添加普通日程时使用，默认 10 分钟。明确说“明天下午三点提醒我开会”时在三点提醒；说“提前十分钟提醒”则提前十分钟。
- 默认时长：未提供结束时间时使用，默认 30 分钟。
- 补播窗口：离线或忙碌时保留提醒，默认 60 分钟。超过窗口标记错过，不在几天后突然播报旧提醒。
- 默认提醒设备：页面或无会话 MCP 创建日程时使用。留空仅产生页面提醒。语音创建由主机自动绑定当前设备，模型不能指定或更换接收设备。

语音示例：

- “查一下明天有什么日程。”
- “看看本周的安排。”
- “明天下午三点提醒我开会。”
- “五分钟后提醒我喝水。”
- “添加明天下午三点开会的日程，提前十分钟提醒。”
- “取消明天下午三点开会的提醒。”

日期或时刻不明确时先追问，可以接着补充“下午三点”。取消时需能唯一定位日程，重名或不明确时要求说明时间，或在面板选择。首版语音每轮处理一项，不支持周期提醒；说“每天提醒”会要求明确单次日期，不会悄悄创建一次性替代。

平台需保持运行才能准时调度；目标设备在线时通过现有 TTS 自动播报。插话只打断播报，提醒保留，待对话空闲后重播。设备离线时保留提醒，在补播窗口内重新连接同一设备后可播报。平台停止时不会自行唤醒电脑或离线机器人；重新启动后检查遗漏提醒。手动取消会屏蔽未播报的通知。时区或设备设置变更只影响新日程，已有日程保留创建时的设定。

`voicehub/mcp_tools/calendar.py` 提供独立 `calendar` 工具，随 `python -m voicehub.common_tools` 的标准 stdio MCP 运行。操作：

```json
{"action":"query","range_start":"2026-10-31T00:00:00+08:00","range_end":"2026-11-01T00:00:00+08:00"}
```

```json
{"action":"create","title":"开会","start_time":"2026-10-31T15:00:00+08:00","remind_minutes":10}
```

取消使用 `{"action":"cancel","event_id":"查询返回的event_id"}`。未来日期仅为格式示例，创建时必须使用未来一年内的实际时间。不能从工具参数传入设备、会话或创建请求标识，这些由宿主环境注入。创建请求幂等；已生成的提醒通知也使用稳定标识，重启不重复建提醒。主机校验非法日期、过去时间、夏令时歧义等情况。

本地数据位于私有 `data/calendar/state.json`，权限 0600，使用进程锁和原子落盘。日程最多 1000 条（含取消记录），查询最多返回 20 条，范围不超过 366 天。管理接口为 `/api/calendar/settings` 和 `/api/calendar/events`，沿用平台访问保护。

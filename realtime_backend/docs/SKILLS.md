# Skills 技能与后台任务

Skill 是一个可复用的受控任务链，组合已注册工具。任务链也可以临时由模型规划；Skill 则提前确定步骤、输入类型和结果引用，让本地 4B 模型主要负责识别触发语、提取参数。这里的技能不是任意可执行脚本。

在「Skills 技能」页面可以启停、运行、修改现有技能，或添加自定义技能。默认包含：

- 系统报告：查询本机 CPU/内存 → 根据结果整理正文 → 生成 Markdown。
- 保存笔记：提供标题和正文 → 保存 Markdown。
- 文档邮件：提供标题、正文、收件人邮箱 → 生成文件 → 创建邮件草稿 → 等待确认 → 提交 SMTP。

语音示例：“帮我生成系统报告”；“保存笔记，标题为提醒，正文为明天测试语音”；“执行文档邮件，标题为周报，正文为本周完成语音测试，收件人为 demo@example.com”。模型不应猜测缺少的参数；信息不全时会要求补充。技能触发语在配置页维护，支持“执行技能 + 技能名称”。

“配置技能”可修改名称、说明、触发语。高级定义包含输入 JSON Schema 和工具步骤；输入支持字符串、数字、布尔值、枚举，最多 8 个字段。步骤最多 8 个，使用 `{"input":"title"}` 绑定输入，使用 `{"from":"file.artifact_id"}` 引用前步结果。工具名、参数和依赖都由主机校验。创建的新技能默认停用，检查后再启用。修改不会影响运行中的版本快照。

对话先给出文字和语音回应，再执行后台任务。插话可以中断当前播报、继续提问，后台 MCP 与 Skill 继续运行；完成后等当前对话和用户语音结束再自动播报。播报被插话时，结果保留，待空闲后再播。断线不取消任务，结果保存在技能页；恢复原会话时可继续播报。页面直接运行的技能只在页面显示结果，不会向任意语音客户端广播。

每会话最多 3 个、全局最多 12 个运行任务，单任务最长 15 分钟。MCP 查询超时可在决策设置中配置，范围 5–600 秒。明确说“取消任务”会请求停止最近一项运行任务；等待确认的工作也可在任务链页面取消。停止或重启时正在发送的外部操作可能已经生效，结果不明时禁止自动重试。

技能页显示后台状态、结果和文件下载。等待补充信息、SMTP 配置或发送确认时，点击“查看任务并补充 / 确认”。SMTP 凭据仍在「MCP 工具 → 发送邮件」中配置，模型不能自行批准发送。应用重启不自动重新执行在途任务，避免重复副作用；TTS 失败时结果仍保留供页面查看。

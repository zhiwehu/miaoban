# 常用 MCP 工具

首批：天气、新闻、本机系统概况。工具通过独立的本地 stdio MCP 服务提供，完成
initialize → notifications/initialized → tools/list → tools/call。保留扩展目录，
本版只允许已实现的三个只读工具，不执行模型给出的命令或任意 URL。

会话先让当前 LLM 根据上下文生成受限 JSON 查询计划；参数经工具端再次校验。
普通聊天继续现有回答链路。工具结果作为不可信数据提供给 LLM，正文流式进入 TTS。
这不要求模型 HTTP 服务支持原生 function calling。

耗时调用前必须先发出并排空简短回应的音频，再启动工具；排空以当前音频时钟估计，
不宣称测量物理扬声器。查询发出 started/completed/failed 事件，超时有中文回应。
打断会取消调用并终止本轮子进程，旧结果不得进入新轮次。

配置：三个工具独立开关、默认城市、新闻源、条数（1–5）和超时（5–30 秒）。
旧配置自动补齐 tools 字段；沿用新连接生效规则。天气/新闻联网，系统信息本地读取。
不读取用户名、进程列表、文件内容、网络地址或环境变量。

验收：真实 stdio 握手及系统查询；天气/新闻的模拟 HTTP 数据与坏响应；
无效参数/禁用工具/输出上限；先播报后执行；打断和超时；配置迁移与现有回归。

运行：`/Users/huzhiwei/ai/mac_voice_agent/.venv/bin/python -m unittest discover -s tests -v`
（在 realtime_backend 目录）。外部 API 的连通性另做只读冒烟检查。

天气网络容错：固定 Open-Meteo GET 的连接超时、断连和502/503/504最多额外重试一次；400/429与证书失败不重试。每次请求总限6秒、连接3秒、读取4秒，两阶段及重试总预算16秒，上层更短超时仍优先。区分城市定位与预报的失败代码，语音及调用卡片显示对应说明；保留取消，不返回缓存天气冒充实时数据。

# 日程与提醒 MCP

内置 calendar 工具支持 query/create/cancel，使用本地私有日程库，不读取系统或云端日历。独立模块拥有 Schema 与 MCP 执行实现。工具面板配置 IANA 时区、默认提前分钟、默认时长、补播窗口与默认提醒设备；支持页面查询、新建、取消。

时间由主机按配置时区处理，拒绝过去时间、无效日期、模糊/不存在的夏令时时间。首版仅单次事件，最多 1000 条，单次查询最多 20 条、范围最多 366 天。模型抽取日期/时刻/相对分钟，主机计算今天/明天/后天/星期和相对提醒。缺时间或周期请求先追问，不猜日期。创建与取消必须是本轮用户明确要求。

语音创建时由主机注入设备/会话和请求标识，模型不能选择提醒接收设备。页面创建使用配置的默认设备，留空只生成页面提醒。原设备在线时通过后台完成播报队列提醒；插话后重播，断线保留。在补播窗口外标记错过。取消会屏蔽未播报的通知。平台需运行才能准时触发，重启后检查未处理提醒，不重复生成已存在的提醒记录。

GET/PUT /api/calendar/settings，GET/POST /api/calendar/events，POST /api/calendar/events/{id}/cancel。所有管理接口沿用现有保护。提醒调度每秒检查，通知 ID 由事件 ID 确定，日程写入和提醒状态使用进程锁与原子文件落盘；创建请求幂等。MCP/后台任务先回应再处理，提醒不通过模型生成事实。

测试覆盖：跨日/时区、DST、范围、幂等、重启与补播、取消、设备隔离、插话队列、实际 stdio MCP、4B 日期参数提取和浏览器面板。

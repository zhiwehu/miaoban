# 动态任务链与独立邮件 MCP

在 MCP 页面展开「SMTP 设置与联系人」，配置服务器、端口、加密方式（SSL/TLS 或 STARTTLS）、账号、发件地址和 SMTP 授权码。465 通常使用 SSL，587 通常使用 STARTTLS；以邮箱服务商提供的设置为准。默认不启用 SMTP，不会发送邮件。

授权码保存在后端 `data/workflows/settings.json`，文件权限为 0600；也可在后端环境设置 `VOICEHUB_SMTP_PASSWORD`，页面授权码留空。不回填密钥，不向模型提供 SMTP 凭据。代码仓库忽略整个 data 目录。联系人格式：

```json
[{"name":"张三","email":"demo@example.com"}]
```

独立服务入口：

```sh
python scripts/run_email_mcp.py
```

也可以在平台下载启动配置。服务提供 `email_prepare`、`email_status`、`email_send`，通过标准 stdio MCP 运行。准备草稿不联网；发送使用主机在用户确认后签发的一次性令牌，普通模型不能自行生成令牌。该配置可用于发现和准备草稿，但外部 MCP 客户端尚无自行授权发送的界面；确认发送由本平台管理。

在 MCP 页输入自然语言目标，或在语音对话中说：

- “生成一份 Word 文档，标题为会议纪要，内容为今天讨论了语音功能，然后发给 demo@example.com。”
- “查询本机 CPU 和内存，把结果写成 Markdown 报告。”
- “生成两个文件，一个 TXT 待办和一个 CSV 清单。”

任务规划器从当前启用的工具中生成最多 8 步计划，程序校验参数、工具白名单、依赖和输出引用。文件由 `document.create` 创建；首版支持 TXT、Markdown、CSV、基本段落 DOCX。文件仅写入受控产物目录，不能指定任意路径。CSV 防止公式注入。不支持 PDF、XLSX 或任意程序/界面操作。小模型仍可能规划失败；校验失败时请求补充目标，不执行无效计划。

邮件步骤通常为文档生成 → 联系人解析 → 准备草稿 → 等待发送确认。页面展示发件人、收件人、主题、完整正文和可下载附件。SMTP 配置缺失时暂停，配置完成后点「继续任务」。语音说「确认发送」或页面勾选核对后点击「确认发送邮件」才会发送；「取消任务」终止后续步骤。确认绑定当前会话、草稿、附件哈希与 SMTP 设置，有效期 10 分钟，修改后需再次确认。

执行中会先回应再调用工具，聊天页保留工具调用记录，MCP 页显示每步状态。已完成步骤保留，明确失败后可以继续；断线、进程中断导致发送结果无法确认时停止重试，避免重复邮件。SMTP 接受仅表示提交成功，不表示投递成功或已阅读。该版本为单机顺序执行，不支持任意后台定时任务或自动重试发送。

开发验证：`python -m unittest discover -s tests -q`。`tests/test_workflow_smtp.py` 使用临时自签证书和仅监听环回的 SMTP 测试服务器，经真实 stdio MCP 验证 DOCX 附件和单次提交，不向外网发送邮件。测试需要本机 openssl。

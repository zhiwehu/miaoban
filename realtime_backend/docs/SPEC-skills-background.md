# Skill 与后台执行

Skill 是可复用的受控任务链，定义名称、触发语、输入 JSON Schema 和最多 8 步的工具计划；参数用 {"input":"参数名"}，前步结果沿用 {"from":"step.field"}。不允许任意脚本、无限循环或模型自行授权发送。预置系统报告、保存笔记、文档邮件技能，用户可修改和启停。

GET/POST /api/skills，PUT /api/skills/{id}；POST /api/skills/{id}/run 接收 arguments。GET /api/operations 查询后台操作，POST /api/operations/{id}/cancel 明确取消。管理员接口沿用平台访问保护。运行保存技能版本与参数快照，编辑不改变在途任务。参数缺失时询问，模型输出必须通过 Schema 和计划校验。普通话题不自动路由到技能。

首次 ToolNotice 立即生成文字与语音回应，再将后续任务交给应用级后台执行器；插话只取消前台回复和音频，不取消 MCP/任务链。单会话最多 3 个、全局最多 12 个运行任务，900 秒总期限。MCP 单次超时可设置 5–600 秒。明确“取消任务”或页面取消才中止执行；外部发送中断仍按未知状态处理，不自动重试。

后台结果和工具事件持久化。完成后在原会话空闲且未检测到用户说话时，创建独立播报轮次。播报也可插话，未完整播放的结果保留等待再播；断线不停止执行，结果仍可在 Skill 页查看，原会话恢复后可继续播报。应用重启不自动重放在途工具，标记中断/结果未知，避免重复副作用。

验证：慢工具运行期间新一轮聊天、播报被插话、断线与恢复、明确取消、参数注入/错误类型、技能变更快照、等待发送确认、后台失败均需覆盖。开发邮件仅本地测试服务。

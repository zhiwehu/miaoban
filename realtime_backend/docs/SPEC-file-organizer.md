# 指定目录文件整理

管理员在 MCP 页配置唯一绝对目录并显式启用。第一版只整理目录第一层普通文件，按扩展名归入文档/图片/音频/视频/压缩包/代码/其他；不递归，不读取文件内容。隐藏文件、符号链接、硬链接和子目录跳过。
MCP file_organizer 仅提供 scan/preview，向模型返回分类数量与计划ID，不返回文件名或文件内容。原 Rex 未训练此分类，按现有动态目录规划；明确整理指令可约束解析。生成计划不移动文件。
管理员 GET /api/files 查看预览详情（仅此受保护接口含文件名）。POST /api/files/preview 生成计划；execute/undo 要求 confirm=true 和完整计划ID，模型不暴露执行工具。页面确认后执行，支持最近一次操作撤销。目录/文件变化或计划过期拒绝执行；目标存在拒绝覆盖，部分失败保留恢复状态。停用/换目录后不能执行旧计划。
根目录用目录FD固定，子目录不跟随符号链接，所有移动在同一配置根内。不能选择文件系统根、用户主目录或包含本平台运行数据的目录。源/目的dev/ino/大小/mtime及根目录身份用于校验，移动使用平台原子的禁止覆盖重命名；不提供永久删除。持久化0600写前日志和flock串行化，崩溃窗口通过文件身份核对恢复；不删除用户创建的分类目录。
UI 遵循现有音乐/MCP面板样式，清楚显示待确认/执行中/部分失败/已完成/已撤销，以及逐个源→目标。执行、撤销按钮为显式动作；测试只使用临时样本目录。无依赖新增。
验收：预览无移动、目录边界/符号链接/覆盖/修改/过期/配置变更、确认门槛、执行撤销、写前日志恢复与部分冲突、MCP只读Schema和语音分发、真实浏览器完整流程与适配。命令 python -m unittest discover -s tests -q；node --test tests/test_mcp_calls.mjs。

# 人工测试清单（2026-10-30）

本轮重点：购物清单、多计时器、物品位置记忆，以及它们对原有聊天、日历和查询工具的影响。先做文字测试，再用喵伴语音重做关键项目，约 30–45 分钟。下表结果栏填 ✓ / ✗ / 未测；不要把未测记为通过。

## 准备与版本

1. 打开 http://127.0.0.1:8765 ，进入 MCP，确认购物清单、多计时器、物品位置记录已启用；需要测试日历、天气、新闻、系统信息时也启用对应工具。记录测试前开关，结束后恢复。Skills 保持暂停。
2. 在“连接实验室”建立文字连接。配置变更后重新连接，让新会话使用新配置。记录所用 LLM、规划方式和设备名称。
3. 测试时每次等当前操作完成，再说下一句。每条都检查三件事：回复、调用卡片的工具/参数/状态、实际存储或计时状态。“收到，我来处理”只算受理，不算执行成功。
4. 所有样本使用“测试”前缀；已有真实数据不要清空。购物清单使用独立名称“人工测试”；物品用“测试护照”“测试雨伞”；计时器用“测试泡面”等名称。
5. 先用 MCP 卡片的“执行”核对直接操作，再测自然语言。直接操作通过但文字失败，一般定位路由/参数提取；文字通过但语音失败，结合识别文本定位 ASR/播放问题。

版本边界：本次提交仓库是 `opensource/miaoban-voicehub`。检查时 8765 进程工作目录是 `/Users/huzhiwei/ai/miaoban/realtime_backend`，相关改动的后端源码与提交副本一致，MCP 页面有一行规划方式说明文字差异。进程内已加载模块版本未验证，本轮没有重启服务。测试反馈请注明“现有8765服务”，不要直接认定它等同于新提交的进程版本。若怀疑版本不一致，先记录问题，再由开发侧核对并重启，不手动覆盖数据目录。

当前工作目录没有显式 active adapter 选择文件，worker 默认候选路径为 v2。新工具可经受限对话模型回退执行；本轮不是 v4/v4b 模型准确率验收，也不需要你切模型。调用卡片允许显示 Rex + 参数提取，或 Rex 未确定后的模型补充决策。

## 六、喵伴实机语音重点

确认设备在线，音量可听到，用手机秒表记录体验。先说唤醒词，再说指令；从界面核对实际识别文本。

- [ ] V01：口述 S01、M01、M02、T01，各完成一次；识别文本、工具参数、结果播报一致。
- [ ] V02：创建测试打断计时器，创建成功后打断其他回复；到点仍提醒，不能因换轮丢失。
- [ ] V03：提醒开始播报时真人插话；当前播报应停止，安静后补播；一次完整播完后不再重复。
- [ ] V04：让设备连续播报，自己不说话，观察 5 次是否被自声误打断。此项是快速抽测，不等同正式 AEC 验收。
- [ ] V05：在普通回答中途说“等一下，只回答你好”；旧轮次语音停止，之后不混入旧回复。
- [ ] V06（可选）：创建 60 秒计时，断开设备，截止后 5 分钟内重连同一设备；应补播，正常播完后不重复。

记录两类延迟：普通指令“说完→首个有用回复”；插话“开始说话→喇叭停止”。没有测量就写主观体验，不写精确毫秒。提醒实际到达时间也记录，排除系统睡眠、设备断线和未启用工具的影响。

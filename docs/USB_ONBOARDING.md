# USB 一体化接入

在运行 VoiceHub 的电脑上，用 Chrome / Edge 打开 http://127.0.0.1:8765/#connections 。准备兼容 EchoEar 猫头、电脑和 USB 数据线即可。

## 1 → 2 → 3

1. **连接设备**：选择 EchoEar，插入猫头 USB，点击“连接 USB”。向导检查芯片、分区与固件，检查通过后进入第 2 步。
2. **配网**：默认“沿用喵伴已保存的 Wi-Fi”，无需填写名称和密码，原有 Wi-Fi 列表保留。电脑需与喵伴处于可互通网络。需要换网络时，选择“连接新的 Wi-Fi”并填写名称与密码；开放网络需明确勾选。点击“备份并连接”，程序自动保存原机备份，无需选择目录。
3. **开始对话**：原机备份全部保存并校验后，程序写入 VoiceHub 连接信息、按需写入新 Wi-Fi，并读回核对和重启。等待上线，唤醒并说“你好”，听到回复后点击确认。

**“沿用 Wi-Fi”使用的是喵伴中已保存的凭据，不是读取电脑密码。** 浏览器不提供直接获取电脑已保存 Wi-Fi 密码的接口；本产品不调用系统钥匙串或额外索取电脑密码。若喵伴没有已保存网络，页面会要求填写，并保留 USB 连接供重试。新网络密码留空不再被解释为自动读取电脑密码。

新填写的网络名称和密码仅通过本机 USB 写入。原机 Flash 含既有网络凭据与设置，自动备份仅发送到本机回环地址的 VoiceHub 服务，保存于数据目录下 `device-backups/<设备MAC>/`，不发送外部服务，不存入浏览器持久存储。目录权限为0700、文件0600；每次保留独立副本，不覆盖旧备份。磁盘写入、同步、回读和浏览器校验成功后才允许写设备。

## 自动准备与读取

设备专用监听与 OTA URL 自动配置，不需要填写 IP、端口或令牌。虚拟 feth、VPN 等接口不作为配网候选；macOS 用系统硬件端口标识真实 Wi-Fi。电脑换网络后，未被在线设备使用的旧监听自动迁移；有设备在使用时保持原连接并明确提示。

完整备份读取 16 / 32 MB，可能需要数分钟。每次读取最多 64 KB，使用 1 KB 串口包、每次仅 1 包在途，逐包确认并核对块摘要，完整块通过后才计入进度。临时中断可自动重连，每个失败块最多两次、整次最多八次，从失败块重读；重连后须核对 MAC、容量、分区和已读的关键设置。持续断线或设备设置改变则停止，不继续写入。

同一浏览器同源接入页通过 Web Locks 协调 USB 归属，直到断开或页面关闭后释放。不要同时在其他浏览器、串口工具或旧版页面操作同一个 USB；这些程序不受该页面锁管理。

## 高级选项

升级、恢复、手动热点配网及设备服务设置均收在“高级选项”。已有兼容固件无需升级。只有通过实机验收的适配版本才能勾选同流程更新，候选版本不会因配网而开放安装。

“立即备份”同样自动保存完整 `.vhdevice` 原机备份。“恢复最近可用备份”自动查找本机保存的最近副本，匹配设备 MAC、分区和容量；损坏文件或启动镜像校验不通过时继续查找更早的副本，无可用备份则停止，用户无需选择文件。旧版手动另存的文件保留在原目录，不会自动扫描或导入。当前应用或 OTA 损坏时，芯片与分区检查通过后可进入“仅可恢复”模式。完整备份恢复应用、NVS 和启动记录，启动记录最后写；不改写引导程序、分区表或资源区。

NVS 追加空间不足时，会在内存中整理已失效的旧记录，完整保留有效记录、未知二进制数据和命名空间索引，并逐项比对；仍保留一页供设备垃圾回收。只有有效配置本身已满、损坏 NVS、设备保护或适配校验未通过时停止，不清空设置。设置写入成功与实际上线分别检查；同名 Wi-Fi 也可能隔离客户端，设备未上线时需核对网络可达性。

## 配置页面

“模型与语音”只保存模型、音频、唤醒、提示词和记录保留，不读取或提交 MCP 设置。工具参数位于各 MCP 卡片的“配置与测试”；规划方式与通用超时位于 MCP 页。

本轮自动化、独立校验与实机验证记录见 `realtime_backend/docs/VALIDATION-usb-onboarding.md`。实际断电恢复和完整新固件安装仍需单独验收。

自动备份接口仅限本机回环访问：`POST /api/clients/echoear-s3/backups` 接受有界完整备份，返回不可变ID；`GET .../backups/{id}` 回读指定副本；`GET .../backups/latest?mac=...&layout=...&flashSize=...` 查找匹配设备的最新完整性有效副本，可用 `before` 继续向前查找。应用和启动记录的语义校验仍由浏览器完成后才允许恢复。

## 提速

设备检查先解析受边界限制的镜像段头，只传回实际镜像长度；仍完整验证芯片、镜像校验和、内嵌摘要、SHA256和已知固件来源。

首次无可用备份时完整读取。再次备份从本机读取已验证的同MAC/分区/容量完整副本；设备处于下载模式，首64KB（含分区、设置和启动记录）始终重读。其余区域由设备计算MD5，与旧副本对应字节比较；吻合才复用，不吻合就重读该区域。MD5只用于传输/变化检查，最终完整快照仍使用SHA256并保存回读验证。每份新备份可独立恢复，不依赖增量链。旧副本缺失或损坏则完整读取；硬件速度需实机测量。
